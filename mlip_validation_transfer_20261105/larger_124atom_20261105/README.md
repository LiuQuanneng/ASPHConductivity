# 已找回的124原子原始计算数据

本补充包解决早先迁移包未包含124原子原始轨迹的问题。数据在原电脑一直保留，并非从未开展大胞计算。已有工作是有限尺寸初筛，尚未证明尺寸收敛。

## 已完成内容

- Li7Y7ZrS16 / mp-754856，31原子结构按(1,2,2)扩胞，共124原子、28个Li。
- 晶胞体积2694.3287205 Å³，沿用原热体积准备的每化学式体积，再固定晶胞弛豫。
- 900 K预平衡2 ps；0.5 fs和1 fs各1 ps NVE检查；随后1 fs、900 K Langevin正式初筛10 ps。
- MACE-MPA-0 medium，float32，原模型SHA256为75428afe3a1d7d8062e19bcaabd5c433623cabf308242ec9fb493e38604fb638。
- 正式轨迹有两段，去除重复时间戳后501帧，0–10 ps，间隔20 fs。
- 重启重复时间为6000、6020、6040、6060 fs，重复帧位置及动量一致。分析时按time_fs去重，不把两段直接无条件拼接。

## 下载及解包

更新仓库或下载本目录所有文件，然后在本目录运行：

```bash
python unpack_and_verify.py
```

只使用Python标准库；验证分卷和每个原始文件SHA256后解包，不启动计算、不覆盖内容不同的已有文件。4个part文件缺一不可。

`raw/`保存完整原始运行目录，包括弛豫、预平衡、两套NVE、10 ps初筛、全部检查点、CSV采样、分析JSON、状态和重启日志。`provenance/`含历史脚本、原始31原子CIF和热体积准备输入。归档共324个文件，历史文件保持原字节，旧路径和PID仅作溯源。

## 新电脑如何接手

1. 先解包和读取validation.json。正式初筛数据在`raw/screen900_confirm/`。
2. 最终检查点为`checkpoint_00010000.json`和其指向的`.traj`，包含随机数状态以及结构、动量；`final.traj`与末帧和该检查点已核对一致。
3. 先分析旧10 ps数据。若决定延长，保留原晶胞、原子顺序、动量、RandomState状态、FixCom、1 fs及Langevin 0.01/fs参数，在新输出目录从10000步继续。
4. 不能直接用上级迁移包针对31原子A/B的worker运行此数据：其断言、起始时间和路径专门针对31原子20 ps历史。需要适配124原子、10000步起点，再做隔离短测试；本补充包不声称已完成GPU续跑测试。
5. 保留原始time_fs的0–10 ps历史；延长段采用连续时间。不同平衡截断的分析必须记录窗口，5 ps截断后仅剩5 ps，不应把5 ps滞后的单个端点差当作充分采样。
6. GPU/CPU后端变化不保证逐位一致。现有数据可恢复，不因迁移强制重新初始化；若改温度、体积、结构或温控，则另建有明确准备流程的计算。

`final_124atoms.cif`仅便于查看结构，不包含速度或随机数状态，不能替代二进制检查点。已有NVE检查是数值检查，不是统计收敛或势函数准确度证明。保持原有资源和墙钟保护，不根据本包自动启动长期MD。
